## 2026-09-13 - [Format truncations, VLA UB, and vasprintf failures]
 **Vulnerability:** Unchecked `vasprintf` return values could result in passing uninitialized/NULL pointers to format strings, causing Undefined Behavior/Segmentation Faults. 0-sized VLAs in epoll wrappers could trigger UB. Format string buffer truncations were also possible due to hardcoded, tight array bounds.
 **Learning:** In C, failing to verify the result of memory-allocating format functions (`vasprintf`) before passing the resulting buffer pointer to another formatting function leads to strict Undefined Behavior. VLAs initialized with user-provided arguments must be strictly guarded against <= 0 sizes.
 **Prevention:** Always check if `vasprintf` returns `-1` and exit early or handle the error gracefully. Clamp VLA declarations to a minimum safe size (e.g., `[size > 0 ? size : 1]`). Ensure buffers receiving dynamically formatted strings (via `snprintf`) have generous padding to prevent silent truncation.
